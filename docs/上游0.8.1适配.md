## 2. 上游 0.7.10 → 0.8.1 改了什么（与我们相关的部分）

- `lib/bridge.js`：`function assistantText(event)` → `export function assistantText(event)`，函数体加 `const content = event?.data?.message?.content; if (!Array.isArray(content)) return ''`；调用点在 `if (text === '')` 之后新增 `rawContent` 守卫（8 行）。上游注释写明原来 `.filter()` 会抛 `Cannot read properties of undefined (reading 'filter')`，整条回复被吞。
- `lib/panel.js`：`panelFooterLinks()` 首位加「账号中心（本插件，本地页面）」`/qqai/accounts`，原 account 条改叫「NapCat 账号（原生页）」。
- `control/lib/server.mjs`：新增页面热读缓存 `freshPage`、`GET /accounts`、`/api/accounts/*` 十余个路由；`/api/napcat/webui` 改为只回裸地址并新增 `GET /api/napcat/open` 302 跳转（隐私收紧）；`'/api/napcat/stop'` 与 `'/api/tts/start'` 之间被 81 行新代码隔开。
- `control/lib/supervisor.mjs`：import `createAccountsApi`；新增导出 `guessHostPort`（宿主端口不再写死 3080）；return 对象插入 `napcatQrFile` / `traceStats` / `accounts`。
- `control/ui.html`：页脚新增 `<a id="accountsLink" href="/accounts"><button>账号中心</button></a>` 与拼 token 的脚本；`napcatLink` 改为走 `/api/napcat/open`。
- 新增 `control/accounts.html`、`control/lib/accounts.mjs`、`control/账号中心.bat`、6 套新单测；`lib/settings-routes.js` +48；`client/client.js` 只改 `CLIENT_VERSION`。
