## 4. 本版补丁面自己动的两处

### 4.1 A 档链锚合并：197 → 182 编辑

链式锚点（`from` 落在我们自己前一条编辑的 `to` 里）随父编辑漂移却各自维护，A 档按「**父 `from` 一字节不变**」的判据并回父编辑：

| 父编辑 | 吸收 | from | to |
| --- | --- | --- | --- |
| `patch-56` `faces:f01` | `patch-60` 的 8 条 faces 编辑 | 5457 不变 | 18518 |
| `patch-56` `bridge:f03` | `patch-60` 的 `bridge:h604–h608`（5 条） | 94 不变 | 9314 |
| `patch-07` `panel:h23` | `patch-53` `panel:h57b` | 745 不变 | 2960 |
| `patch-07` `control/lib/supervisor.mjs:h12` | `patch-53` `sup:h59` | 127 不变 | 12215 |

校验：`_replay182`（pristine + 全量重放）与 `v0820-patched` 逐字节相同（169 vs 169、onlyA 0 / onlyB 0 / 内容不同 0），`--verify` = 0 / 182 / 0。

### 4.2 `patch-63` 打包白名单：182 → 183 编辑

`package.json` 的 `files` 只列代码目录 ⇒ 以 `file:` 本地源安装时 pnpm 按白名单打包，插件根三份用户数据（`qq-persona.txt` / `qq-persona.txt.bak` / `qq-control.json`）整层丢掉。`patch-63` 把这三行写进 `files`，安装形态才与手工铺装等价。
