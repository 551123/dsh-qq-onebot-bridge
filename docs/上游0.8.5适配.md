## 3. 补丁器侧的一处门禁调整

`check.mjs` 第 8 项（fork 树 == 线上树）的 skip 列表加 `tools`：

```js
'--skip', '.git,.gitattributes,.gitignore,examples,ext,PATCHES.md,上游*,qq-bridge-debug.log,tools'
```

理由：上游 `package.json` 的 `files` 白名单不含 `tools`，`npm pack` 形态的线上树永远没有 `tools/audit.mjs`，而 fork 源码树有。这是**安装形态差异**，不是补丁差异 —— 与 `.gitattributes`、`examples` 同类处理。
